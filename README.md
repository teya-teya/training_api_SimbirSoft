## Учебный проект в SimbirSoft Панферовой Анастасии

📋 Описание проекта
Проект для обучения автоматизации тестирования API с проверкой данных в базе данных

Блок A (Тестирование API)

🛠 Используемые технологии
Java
Maven
Rest Assured
TestNG
JDBC

📌 Основные возможности

* Отправка API-запросов (GET, POST, PUT, DELETE)
* Проверка ответов API (status code, body)
* Валидация данных в базе данных через JDBC
* Проверка создания, изменения и удаления объектов

Установленное ПО
Java 17
Maven 3.9.12
IntelliJ IDEA Community
Postman
Git

📂 Структура проекта

* client — работа с API (запросы)
* models — модели данных (DTO)
* db — работа с базой данных (JDBC)
* tests — автотесты

Проверка окружения
java -version
mvn -version

Статус
Окружение настроено, проект инициализирован. Реализуются API автотесты с проверкой БД.
